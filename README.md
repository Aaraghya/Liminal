# Liminal
Built by Team Onsight.

## Features
1) Emotion based onboarding and personalized dashboard
2) Secure authentication and user profiles 
3) Bilingual AI companion for emotionally validating conversations
4) Guided breathing exercise (4 7 8 technique)
5) Private journaling with emotion tagging, timeline & exporting
6) Anonymous community interaction and support
7) Unsent messages space for emotional expression
8) Dark and light theme support


## Architecture: 
The application follows a client side single page architecture with secure authentication, protected routes, server side AI integration, and database level access control. The system separates UI, logic, and data handling to maintain security and scalability.

## Design Principles
- No scoring / ranking systems
- No gamification
- Privacy first interaction
- Calm and non-performative user experience
